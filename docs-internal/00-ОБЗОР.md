# 00 · Обзор продукта

> Обновлено: 2026-07-13. При изменении состава модулей — обнови таблицу ниже.

## Что это

**Аналитический портал STH** (`https://portalsth.ru`) — внутренний инструмент компании СТХ
(подбор персонала / аутсорсинг): набор веб-модулей на одном VPS + локальная AI/телефонная
инфраструктура на ПК владельца. Ядро активной разработки —
**автообзвон кандидатов голосовым ботом** (модуль voicecall).

| Роль | Что использует |
|---|---|
| Владелец (Максим) | всё; единственный админ |

## Модули портала

| Модуль | Путь в репо | Что делает | Активность |
|---|---|---|---|
| **voicecall** | `voicecall/` | Автообзвон кандидатов: загрузка базы → бот звонит по сценарию → воронка/вердикты. UI: конструктор сценариев + кампании | 🔥 основная разработка |
| **tasks** | `tasks/` | Задачник с Gantt, дашбордом, roadmap-графом. Бэкенд `tasks/api/main.py` — общий для всего портала | активен |
| sales | `sales/` | Дашборд продаж (React/Vite, единственный собираемый фронт) | стабилен |
| analyst | `analyst/` | Аналитические проекты | стабилен |
| chat | `chat/` | Чат с LLM (через Ollama-прокси) | стабилен |
| finance | `finance/` | Финансовый дашборд | стабилен |
| hr-game | `hr-game/` | Геймификация для HR | стабилен |
| kp | `kp/` | Генератор коммерческих предложений | стабилен |
| month | `month/` | Месячный отчёт | стабилен |
| okk | `okk/` | ОКК (отдел контроля качества) | стабилен |
| recruiter | `recruiter/` | AI-рекрутёр (Streamlit на VPS :8501) | стабилен |
| validator | `validator/` | Валидация кандидатов (веб-анкета) | стабилен |
| wb | `wb/` | Дашборд Wildberries | стабилен |

Все модули кроме sales — статические `index.html` (vanilla JS), которые ходят в общий
бэкенд `tasks/api/main.py` (FastAPI, ~116 эндпоинтов, SQLite).

## Ключевые цифры (на 2026-07-13)

- Бэкенд: 1 файл `tasks/api/main.py`, ~5900 строк, 116 эндпоинтов, 14 таблиц SQLite
- Голосовой стек: ~5800 строк Python в `voicecall/`
- Тесты: ~236, только в `tasks/api/tests/` (pytest)
- Инфраструктура: 1 VPS (1 vCPU, 960 МБ) + ПК владельца (агент, Ollama, Vosk, Silero)
