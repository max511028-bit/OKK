## Правило №1

**Любая доработка, меняющая поведение системы, должна обновлять соответствующий
документ в этой папке в том же коммите.** Матрица соответствия — в
`ПРАВИЛА-ОБНОВЛЕНИЯ.md` (до её появления — здравый смысл по оглавлению выше).
