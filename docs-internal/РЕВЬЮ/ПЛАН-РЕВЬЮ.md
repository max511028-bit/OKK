# План этапа 4 — код-ревью портала (review-only)

> Режим: **только ревью, ничего не удаляем и не правим.** Все находки →
> `НАХОДКИ.md` с категориями. Правки — отдельными задачами ПОСЛЕ согласования.

## Категории находок (используются в НАХОДКИ.md)

| Тег | Значит |
|---|---|
| 🗑 УДАЛИТЬ | мёртвый/легаси код, дубли, неиспользуемое |
| 🔧 ПОЧИНИТЬ | баг, риск безопасности, потеря данных |
| ➕ ДОРАБОТАТЬ | улучшить надёжность/UX/функцию (не баг) |
| ♻️ РЕФАКТОРИНГ | структура/качество кода без смены поведения |
| ❓ ПРОВЕРИТЬ | нужно решение владельца (жив ли модуль, нужен ли эндпоинт) |

Severity: 🔴 высокий · 🟠 средний · 🟢 низкий.

## Блоки ревью (порядок = по ценности)

| # | Блок | Что смотрим | Статус |
|---|---|---|---|
| 1 | **Безопасность** | SQL-инъекции, path traversal, XSS, покрытие авторизации, секреты в логах/коде, открытые пишущие эндпоинты | ✅ пройден |
| 2 | **Данные и надёжность бэкенда** | бэкапы БД, обработка ошибок, гонки, NOT NULL-ловушки, идемпотентность миграций, транзакции | ⏳ |
| 3 | **Голосовой агент** | пайплайн, патчи pyVoIP, обработка обрывов, утечки потоков/памяти, таймауты, качество распознавания | ⏳ |
| 4 | **Фронтенды (все 15)** | XSS-эскейпинг, дубли кода, мёртвые обработчики, доступность, размер/производительность, единообразие | ⏳ (делаем все — реш. владельца) |
| 5 | **Мёртвый код и легаси** | ngrok-эра, cloudflared, inject-скрипты, дубли-алиасы, отладочные скрипты, устаревшие доки | ⏳ |
| 6 | **Инфраструктура/деплой** | CI без тестов, отсутствие бэкапов, зомби-задачи, чужие правки скриптов, secrets в CI | ⏳ |
| 7 | **Тесты** | покрытие, красные тесты, что не покрыто, качество | ⏳ |
| 8 | **Итог** | приоритизация всех находок, roadmap правок | ⏳ |

## Метод

- Read-only: grep-паттерны + чтение подозрительных участков.
- Каждая находка: файл:строка, что, почему риск/зачем, рекомендация.
- Где есть обоснование в комментариях кода — отмечаем «обосновано», не спорим.
- В конце (блок 8) — сводная таблица с приоритетами; правки — отдельно, по твоей команде.

## Оценка объёма

~5900 строк бэкенда + ~5800 Python агента + 15 фронтов (часть по 3000+ строк).
Реалистично — несколько проходов. Блоки 1-3 (бэк+агент) — приоритет; блок 4 (все
фронты) — самый объёмный, дробим по модулям.
