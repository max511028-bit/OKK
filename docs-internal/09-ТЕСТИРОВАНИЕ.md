# 09 · Тестирование

> Обновлено: 2026-07-13.

## Как запускать

```bash
cd <корень репо>
python -m pytest tasks/api/tests/ -q        # весь набор (~30с, ~236 тестов)
python -m pytest tasks/api/tests/test_voicecall_dispatch.py -q   # один файл
```

CI тесты НЕ гоняет (техдолг) — прогон руками перед push обязателен.

## Правила (жёсткие)

1. **Все тесты — только в `tasks/api/tests/`.** Никаких тестов рядом с кодом.
2. Голосовые модули (`voicecall/*.py`) тестируются оттуда же через
   `sys.path.insert(VOICECALL_DIR)` — см. `test_voicecall_dialog.py` как образец.
3. Сеть/LLM в тестах — только моками (`da._llm_ask = lambda ...`); реальные вызовы
   edge-tts/Ollama/Novofon в тестах запрещены (CI их не имеет).
4. Каждый вылеченный боевой баг получает регресс-тест с комментарием
   «реальный случай YYYY-MM-DD: ...» — так накоплена вся текущая база.

## Карта тестов

| Файл | Покрывает |
|---|---|
| `test_voicecall_dispatch.py` | диспетчеризация обзвона: claim/result/recheck, воронка, переклассификации, авто-повторы, флаги ⚠ |
| `test_voicecall_dialog.py` | детекторы: автоответчик, AI-секретари, ринг-бэк, «перезвоните», филлеры |
| `test_voicecall_recheck.py` | пере-валидация по записи: grounding, возраст, «не выдумывать» |
| `test_voicecall_scripts.py` | конструктор сценариев: warnings, настройки голоса |
| `test_voicecall_tts.py` | ключ кэша TTS, rate→atempo, обрезка тишины |
| `test_tasks_newdue.py`, `test_purge_trash.py`, `test_roadmap_new_sheet.py` | задачник |
| `test_ai_cache.py`, `test_ai_logs.py` | AI-кэш/логи. ⚠ `TestStreamReplay::test_replay_yields_chunks_and_final` — давно красный (async-генератор, техдолг) |
| `test_auth.py`, `test_agent_status.py`, `test_analyst_endpoints.py`, `test_recruiter_logic.py` | авторизация, heartbeat, аналитик, рекрутёр |

## Чего тесты НЕ покрывают (знать при правках)

- Реальный SIP/RTP-тракт (pyVoIP-патчи) — проверяется только живым звонком.
- Фронтенды (никаких JS-тестов).
- CI/деплой (smoke в CI ограничен health-чеками).

Финальная проверка голосовых правок = **тестовый звонок на свой номер** (см. 08-RUNBOOK).
