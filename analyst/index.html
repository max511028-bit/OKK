Помощь по формулам

Используй [имя колонки] для ссылки. Поддерживаются:
Арифметика: [выручка] - [затраты], ([a]+[b])*2
Сравнение: == != > < >= <=
Логика: AND OR NOT
IF: IF([сумма]>1000000, "крупный", "мелкий")
Строки: CONCAT([фио], " (", [город], ")"), UPPER([s]), LOWER([s]), TRIM([s]), LEN([s])
Содержит: CONTAINS([имя],"иван"), STARTSWITH([s],"М"), ENDSWITH
Regex: REGEX_EXTRACT([s], "\\d+", 0)
Числа: ROUND([x],2), ABS([x]), COALESCE([a],[b],0)
Даты: DATE_DIFF([d1],[d2],"days"), DATE_PART([d],"year"), DATE_ADD([d],30,"days"), TODAY()
Пример: IF(AND([выручка]>100000, NOT(CONTAINS([клиент],"тест"))), ROUND([выручка]*0.13,2), 0)
