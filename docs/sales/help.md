# Дашборд Продажи (Bitrix CRM)

## Что показывает
Лиды и сделки из Битрикс24: воронка, потери, конверсия, сквозная аналитика.

## Ключевые метрики
- **Воронка лидов**: Поступило → Удалось дозвониться → Целевые.
- **Воронка сделок**: Создано → Квалификация → Проработка → КП → Согласование → Договор.
- **Сквозная конверсия** — доля лидов, дошедших до подписанного договора.
- **Уверенные связи** — лид ↔ сделка связаны по телефону/email/UTM/roistat.

## Закрытые сделки
Сделки с флагом `Сделка закрыта = да` автоматически считаются потерями, даже если стадия выглядит активной (например «Поиск контактов»). Это решает проблему «нецелевых», которые не переименовали стадию.

## Импорт свежих данных
1. На VPS обнови `/var/www/okk/sales/data/leads.csv` и `deals.csv` (выгрузки из Битрикса).
2. На дашборде нажми **«Лиды из data»** и **«Сделки из data»** в шапке.

## Темы
Кнопка ☀️/🌙 в подвале сайдбара переключает светлую/тёмную тему. Выбор запоминается.

## Если что-то сломалось
Если воронка показывает старые данные — нажми Ctrl+Shift+R (хард-релоад) и снова импортируй из data.
