# Дашборд ОКК (Контроль качества)

## Что показывает
Сводка по качеству работы складов / бригад / смен: KPI, зоны (зелёная/жёлтая/красная), брак, NPS.

## Ключевые метрики
- **KPI** — суммарная оценка склада по чек-листу проверок (0–100%).
- **Зона** — цветовой светофор: зелёная ≥ 80%, жёлтая 60–79%, красная < 60%.
- **Брак %** — доля забракованных единиц от обработанных.
- **NPS** — рейтинг от клиентов склада.

## Что спросить у ИИ
- «Какие склады в красной зоне на этой неделе?»
- «Где растёт брак за последний месяц?»
- «План действий по слабым складам.»

## Если что-то сломалось
Пиши в Задачник → задача на «STH портал». Если данные не подгрузились — F5 + проверь дату последнего импорта в шапке.
