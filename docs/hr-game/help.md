# HR-игра / Отработка возражений

## Что показывает
Тренажёр для рекрутёров: ИИ играет роль кандидата с возражениями, ты отрабатываешь.

## Как пользоваться
1. Выбери сценарий («мало платят», «не хочу ГПХ», «график не подходит» и т.п.).
2. Веди диалог в чате — ИИ играет за кандидата.
3. После 5–10 реплик нажми «Завершить» — получишь оценку и разбор.

## Что спросить у ИИ
- «Кандидат говорит "мало платят" — отработай.»
- «Кандидат сравнивает с другим работодателем.»
- «Кандидат хочет "попробовать один день" — закрой.»

## Если что-то сломалось
ИИ долго думает (> 10 сек) — возможно, перегружена модель. Перезагрузи страницу или подожди.
