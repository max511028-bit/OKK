# voicecall — голосовой обзвон кандидатов

MVP-модуль: бот звонит реальным кандидатам через SIP-провайдер (Novofon),
говорит сценарий валидации, слушает ответы, сохраняет результат в портал.

Архитектура: Python-скрипт на твоём ПК подключается как SIP-клиент к
Novofon, инициирует звонки. Голос — silero TTS (бесплатно).
Распознавание — Vosk (уже работает на VPS). Логика — наш Qwen.

## Структура

```
voicecall/
├── README.md                ← этот файл
├── requirements.txt         ← Python-зависимости (pyVoIP)
├── install_windows.ps1      ← установщик зависимостей (один клик)
├── env.example              ← шаблон файла с креденшалами
├── test_register.py         ← проверка: подключается ли SIP к Novofon
├── test_call.py             ← проверка: реальный звонок на твой мобильник
└── (далее) полный движок диалога, очередь обзвона, интеграция с порталом
```

## Где хранятся секреты

Креденшалы Novofon (логин, пароль, API) лежат в файле
`C:\ProgramData\sth\voicecall.env` на твоём ПК. **В git не уходят.**
Шаблон см. в `env.example`.

## Этапы запуска (по порядку)

### Этап 0 — установка зависимостей (один раз)

В PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File scripts\..\voicecall\install_windows.ps1
```

### Этап 1 — сохрани креденшалы

Создай файл `C:\ProgramData\sth\voicecall.env` со своими данными
из личного кабинета Novofon (см. `env.example`).

### Этап 2 — проверь регистрацию (баланс НЕ нужен)

```powershell
python voicecall\test_register.py
```

Ожидаемый вывод: `✅ REGISTERED to sip.novofon.ru`. Если так — креденшалы
рабочие и сеть пропускает SIP. Если нет — смотри что в выводе, дальше
разберёмся.

### Этап 3 — реальный звонок (баланс нужен)

После того как Novofon подтвердит документы и ты пополнишь баланс:

```powershell
python voicecall\test_call.py +79991234567
```

Где `+79991234567` — твой ВТОРОЙ мобильник для теста. Бот должен:
1. Позвонить на этот номер
2. Когда поднимешь — проиграть тестовый звук (440Hz, 3 сек)
3. Положить трубку

Если услышишь сигнал в трубку — этап пройден, можем строить дальше
полноценный сценарий с речью.
