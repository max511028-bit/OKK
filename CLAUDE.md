# Правила работы с репозиторием OKK (портал STH)

## Документация — ОБЯЗАТЕЛЬНО

Вся актуальная документация — в **`docs-internal/`** (старый `DOCS.md` устарел).

**Перед началом работы** прочитай минимум:
- `docs-internal/00-ОБЗОР.md` — что это за система;
- `docs-internal/08-RUNBOOK.md` — если нужно что-то проверить/перезапустить.

**После любой доработки, меняющей поведение системы**, обнови документацию
**в том же коммите** по матрице `docs-internal/ПРАВИЛА-ОБНОВЛЕНИЯ.md`
(изменил эндпоинт → 02, схему БД → 03, логику звонка → 04, топологию → 01,
деплой → 06, секрет → 07, новый типовой сбой → 08, техдолг → 10, крупная
фича → CHANGELOG). Коммит без обновления доки — неполный.

## Жёсткие правила

1. **НИКОГДА не коммить** `scripts/install-ai-watchdog.ps1` и
   `scripts/start-ai-tunnel.ps1` — в рабочей копии лежат чужие локальные правки.
2. **Секреты не попадают в git.** Значения — только в `docs-internal/СЕКРЕТЫ.local.md`
   (он в .gitignore). Реестр без значений — `docs-internal/07-ДОСТУПЫ.md`.
3. **Тесты — только в `tasks/api/tests/`** (pytest). Прогон: `python -m pytest tasks/api/tests/ -q`.
   Известный не связанный красный: `test_ai_cache.py::TestStreamReplay` (техдолг).
4. **Сценарии обзвона правит только владелец руками** через конструктор на портале —
   не менять их из кода/API без явной просьбы.
5. Кириллица ломает Windows-консоль (cp1251): логи читать через
   `python -c "import io; ..."` с encoding='utf-8', не через `cat`/`Get-Content`.

## Деплой (краткая шпаргалка)

- `tasks/api/main.py`, фронтенды → `git push origin main` → CI сам деплоит на VPS
  и рестартит tasks-api (~3-4 мин). Smoke: `curl https://portalsth.ru/tasks/api/health`.
- `voicecall/*.py` (агент) → работает ЛОКАЛЬНО на этом ПК: после правки перезапусти
  задачу `STH-Dispatch-Agent` (PowerShell: `Stop-ScheduledTask`/`Start-ScheduledTask`).
- Задачи автозапуска ПК запускаются через VBS-шим `C:\ProgramData\sth\run-hidden.vbs` —
  не менять на прямой powershell (вернутся вспышки окон).

## Инфраструктура одним абзацем

VPS (portalsth.ru, 1 vCPU/960МБ) — только nginx + FastAPI + SQLite; всё тяжёлое
(Ollama, Vosk, Silero, SIP-агент обзвона) — на этом ПК, связь через SSH reverse-туннель
(11434→21434, 5001→25001). Агент недостижим извне — он сам поллит портал.
Детали: `docs-internal/01-АРХИТЕКТУРА.md`.
